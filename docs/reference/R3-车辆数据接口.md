# R3 车辆数据接口（DSI）

[← 平台参考](README.md)

车机通过网关能收到大量车辆数据，HMI 里用 DSI 接口订阅（用法见 [R2](R2-HMI-J9-Java.md) 第 5 节）。下面是途锐 3.0T 上实测的结果。**哪些项可用、单位、无效值每台车都可能不同**，换车型一定先做只读探针：只订阅、只记日志，不写任何东西。

通用规则：【MH2p 通用】

- 每个数据组都有一个对应的 ViewOptions，里面每项的 state：**0 = 没有这项，1 = 装了但当前无效，2 = 可用**。
- 回调的有效标志是 `1` 才用。
- 无效值不会单独标出来，而是一个固定的"哨兵"数（见各表），必须过滤。

## 1. DSICarVehicleStates

| 属性 | 内容 |
| --- | --- |
| 12 | 高频数据的 ViewOptions |
| 13 | 中频数据的 ViewOptions |
| 14 | 高频数据 `DynamicVehicleInfoHighFrequent` |
| 15 | 中频数据 `DynamicVehicleInfoMidFrequent` |
| 16 | 半静态数据的 ViewOptions |
| 17 | 半静态数据 `SemiStaticVehicleData` |

### 高频（属性 14）

刷新率：着车 8～10 次/秒，熄火约 3 次/秒（可能只在变化时发）。【途锐实测】

| 字段 | 单位 / 含义 | 途锐实测 |
| --- | --- | --- |
| `vehicleSpeed` | 表显车速，km/h（整数） | 可用。比真实车速高几个百分点 |
| `realVehicleSpeed` | 真实车速，km/h（结构同 `CarBCSpeed`） | 可用。桩类里没有，反射读 |
| `engineSpeed` | 转速 rpm | 可用。怠速约 660 |
| `currentOutputPower` | 功率 kW | 可用 |
| `currentTorque` | 扭矩 Nm | 可用。ECU 估算值，不是传感器测的；功率 = 扭矩 × 转速 ÷ 9549，每一行都吻合 |
| `longitudinalAcceleration` | 纵向加速度 **m/s²**（步长 0.16） | 可用。起步 +3.2、刹车 −5.12 |
| `lateralAcceleration` | 横向加速度 **g** | 可用。和横摆角速度 × 车速推算一致；原车运动显示的代码也只把纵向除以 9.81 |
| `acceleratorPosition` | 油门开度 % | 可用 |
| `brakePressure` | 制动压力，约 bar | 可用 |
| `wheelAngle` | 方向盘转角 ° | 可用 |
| `yawRate` | 横摆角速度 °/s | 可用。反射读 |
| `espWheelVelocityFrontLeft` / `FrontRight` / `RearLeft` / `RearRight` | 四轮轮速 km/h | 可用。极低速时一直读 0（起步后第一个非零值已有好几 km/h） |
| `espOversteering` / `espUndersteering` | ESP 过度 / 不足转向 | state 2，数值没分析 |
| `absChargingAirPressure` | 增压（绝对） | state 2，但一直是 0 |
| `relChargingAirPressure` | 增压（相对） | 最大见过 40，单位不明 |
| `powermeter` | 功率表 | state 0；值 4093 = 无效 |
| `allWheelDriveTorque`、`relAllWheelDriveTorque`、`torqueDistribution*` | 四驱扭矩、四轮扭矩分配 | state 0，没有 |
| `shiftLight` | 换挡提示灯 | state 1（装了但无效） |

### 中频（属性 15）

只在数值变化时发。【途锐实测】

| 字段 | 单位 / 含义 | 途锐实测 |
| --- | --- | --- |
| `gearboxOilTemperature` | 变速箱油温 °C | 可用 |
| `automaticGearShiftTransMode` | 换挡杆位置 | 按车速推断：1 = P、2 = R（最高 7 km/h）、3 = N、4 = D；5 只在停车时短暂出现过，含义未确定 |
| `currentGear` | 挡位 | 原厂 DSI 行驶中常报 0（偶见 1/2），**不是**实际挡位号；`v21.0` 起 `Dash.java` 已加入基于 2023 款 3.0TSI 实车采埃孚 8AT 锁止齿比的兜底推算输出 `D1～D8 / S1～S8`（注：2.0TSI 或 eHybrid 纯电/混动模式下可能存在齿比或解耦偏差） |
| `aCCIsActive` | ACC 是否在工作 | 桩类里没有，反射读。ACC 只是待命（没在控车）时是 false；真正控车时的值还没在行车中确认 |
| `acceleratorKickDown`、`driverIsBraking` | 强制降挡、是否在刹车 | 有回调，没细看 |
| 车门、安全带等 | | 有回调，没细看 |

### 半静态（属性 17）

| 字段 | 途锐 3.0T 报的值 |
| --- | --- |
| `maxOutputPower` | 265 kW（注：大众官标 3.0TSI 额定最大功率为 `250 kW / 340 PS`，此处为实车 DSI 属性 17 上报上限） |
| `maxTorque` | 450 Nm |
| `maxChargingAirPressure` | 2.5 bar |

### 扭矩口径（途锐实测）

- 厂家公布的扭矩按国标（GB/T 17692）在发动机台架上测，是曲轴端的。车机报的扭矩和它同一端，可以直接比。
- 油门 68% 加速时，2700～3800 rpm 扭矩稳定在 450～460 Nm、持续约 3 秒，比额定 450 Nm 略高。原因可能是估算误差、短时超增压，或者是没扣摩擦损失的"内部扭矩"口径，接口里没写，要靠大油门记录判断。

## 2. DSICarKombi（行车电脑）

| 属性 | 回调 | 内容 | 途锐实测 |
| --- | --- | --- | --- |
| 4 | ViewOptions | 各项是否可用 | |
| 6 | `updateBCCurrentConsumption1` | 当前消耗（值 + 单位码） | 单位码 0 = L/100km，2 = L/h（停车时自动切换）；停车时偶尔报 **32770** = 无效。L/100km 最大只报 **40.9**（两段行程里 121 次正好 40.9），是上限不是真实值 |
| 8 | `updateBCCurrentRange1` | 续驶里程 km | 可用 |
| 10 | `updateBCTotalDistance` | 总里程（`CarBCDistance.distanceValue`，double） | 可用，报整数 km（如 36666.0）。仪表可清零的「分里程表（里程）」（俗称 Trip）不发给车机，只能用"总里程 − 清零时的总里程"推算 |
| 11 | `updateBCShortTermAverageConsumption1` | 自启动起平均消耗 | 可用 |
| 13 | `updateBCShortTermGeneral` | 自启动起：里程、平均车速、行驶时间 | 可用 |
| 17 | `updateBCCycleAverageConsumption1` | 自上次加油后平均消耗 | 可用 |
| 19 | `updateBCCycleGeneral` | 自上次加油后：里程、平均车速、行驶时间 | 可用 |
| 14 | `updateBCLongTermAverageConsumption1` | 累计平均消耗 | 可用 |
| 16 | `updateBCLongTermGeneral` | 累计：里程、平均车速、行驶时间 | 可用 |
| 23 | `updateBCTankLevel1` | 油量，**只有百分比** 0～100 | 升数要自己乘油箱容积（中规燃油 2.0T/3.0T 为 90 L，中规 2021–2022 eHybrid 为 76 L，欧规标配 75 L） |
| 63 | `updateBCCoolantTemperature` | 发动机冷却液温度 | 热车后一直 90°C |
| 64 | `updateBCOilTemperatureValue` | 机油温度 | 冷车时 state ≠ 1、值 **−3276.5** |
| 65 | `updateBCOutsideTemperature` | 车外温度 | 同上，要过滤 −3276.5 |

- 三个存储器（按 2018.07 原厂说明书官称：`自启动起存储器` = ShortTerm、`自上次加油后存储器` = Cycle、`累计存储器` = LongTerm；其中累计存储器超 19h59m/99h59m 或 1999.9/9999.9 km 时自动清零）就是原车"行驶数据"页的三页，数值已和原车核对一致。三个 General 结构相同：里程 `CarBCDistance`、平均车速 `CarBCSpeed`、行驶时间 `CarBCTime`（分钟）。【途锐实测】
- 行车电脑某个存储器刚清零时，它的平均消耗报 **3277.0**，要当无效值过滤。【途锐实测】
- 温度结构里有 `temperatureValue`、`temperatureUnit`、`state`。原车在机油到约 60°C 前不显示机油温度，对应的就是 state ≠ 1 这段时间。【途锐实测】
- 单位码 1（推测 km/L）没见过。【未验证】

## 3. 扩展实测 DSI 接口（v21.0+：直接胎压、车身倾角与 GNSS 海拔）

自 `v21.0` 起在 `src/hud-java/vwcn/ExtraDSI.java` 中通过反射动态解析属性名（带回退属性号）只读接入以下 3 组实车 DSI 接口：【途锐实测】

| DSI 接口 | 属性名（回退属性号） | 内容与单位 | 途锐实测与配置边界 |
| --- | --- | --- | --- |
| `DSICarComfort`（`de.vw.mib.dsi.carcomfort` / `org.dsi.ifc.carcomfort`） | `ATTR_RDKTIREDISPLAY`（`37`） | 四轮直接式胎压（RDK，65 模块 / J502，按单位码换算为 `bar`）及低压告警位掩码 | 过滤哨兵值 `0/254/255/≥6000` 及范围外值；中规 2022/2023 全系标配直接式 RDK，静止未发射信号时灰显上次值 |
| `DSICarDrivingCharacteristics`（`org.dsi.ifc.cardrivingcharacteristics`） | `ATTR_TADCURRENTROLLANGLE`（`22`）、`ATTR_TADCURRENTPITCHANGLE`（`23`） | 车身侧倾角（`roll`）与俯仰角（`pitch`），单位 `°` | **需配备空气悬架底盘**（2018.07 说明书 PDF 20 明确仅空悬车显示纵/横向倾斜度；无空悬车型如中规 2021–2022 eHybrid 无上报） |
| `DSINavigation`（`org.dsi.ifc.navigation`） | `ATTR_SOPOSPOSITION`（`28`） | GNSS 海拔高度（`alt`），单位 `m` | 实车直读有效，无需激活原车导航 |

- **踩坑实录：RDK 胎压 `pressureUnit` 在 DSI 层与 ASL 层枚举顺序不一致（[#14](https://github.com/a78c7/touareg-cn-carplay-mods/issues/14)）**：早期按 HMI ASL 习惯顺序换算时，车机单位设为 `psi` 或 `kPa` 的车辆会出现仪表信息框胎压偏低。反汇编车机原厂 `HsmTargetCarService.dsiCarComfortUpdateRDKTireDisplay` 确认 DSI `CarConstants` 枚举与比例系数如下（已在 `v23.2` 的 `ExtraDSI.toBar()` 修正）：【途锐实测】
  - `0 = PRESSUREUNIT_BAR`：`0.1 bar/LSB`（如原始值 `24` → `2.4 bar`）；
  - `1 = PRESSUREUNIT_PSI`：`0.5 psi/LSB`（如原始值 `70` → `35.0 psi` → `2.41 bar`，此前误将 `1` 当作 `kPa` 且漏乘 `0.5`）；
  - `2 = PRESSUREUNIT_KPA`：`10 kPa/LSB = 0.1 bar/LSB`（如原始值 `24` → `240 kPa` → `2.4 bar`，同时兼容 `≥80` / `>800` 细分刻度上报）。

## 4. 车上看不到的数据

- 增压（实测为 0）、点火角、爆震、空燃比、进气温度这些 ECU 内部数据，DSI 里没有。要用诊断工具读。【途锐实测】
- 原车仪表上的 G 值小窗口动画是仪表自己画的，车机改不了。【途锐实测】
