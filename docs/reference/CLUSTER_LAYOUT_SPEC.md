# 途锐 12 英寸全液晶仪表（数字驾驶舱 / Digital Cockpit）`1920×639` 精确界面几何规范

> 本规范基于 2023 款国行途锐（`MH2p_CN_VWG36_P2878`）实车正视标定照，结合已知渲染卡片（`x=5..300`、`x=1620..1915`、`y=164..508`）逐像素反算校准。所有使用 AI 编写 `v23` 60fps 自定义皮肤（`my_theme.js`）或调试仪表布局的车主与开发者，均应以此文档为唯一坐标真相源。

## 2. 原车自绘遮挡区（不可逆物理覆盖，禁止摆放关键信息）

大众仪表固件（FPK）会在 Window `58` 之上叠加以下 4 块原车图层，**皮肤画在这些区域的内容会被直接盖死或叠字**：

### 2.1 顶部双层遮挡（`y = 0 .. 154`）
- **`y = 0 .. 82`（全黑不透明原车状态栏）**：方向罗盘、时钟（中心 `x = 965`）、辅助图标、车外温度。画在此区域**完全不可见**。
- **`y = 82 .. 154`（半透明原车导航顶栏）**：剩余距离、当前路名、预计到达时间，原车白字盖在最上层。
- **`y = 154 .. 164`（`10 px` 呼吸留白缝）**：所有自定义卡片/表盘顶边建议严格对齐 **`y >= 164`**。

### 2.2 左下 / 右下原车斜梯形（挡位与车速，切勿按旧文档 `355 / 1565` 估算！）
> ⚠️ 实车正面像素校准发现：两块斜梯形底边比早期估算宽了约 `110 px`，若侧翼或底部组件伸入此区间会被直接切角遮挡。

| 遮挡区 | 精确 4 顶点多边形（顺时针） | 说明 |
| :--- | :--- | :--- |
| **左下原车挡位梯形**（`P / D / S`） | `(0, 518) → (314, 518) → (468, 639) → (0, 639)` | 顶边 `y = 518`，斜边从 `x = 314` 扩至底边 `x = 468` |
| **右下原车车速梯形**（`0 km/h`） | `(1612, 518) → (1920, 518) → (1920, 639) → (1458, 639)` | 顶边 `y = 518`，斜边从 `x = 1612` 扩至底边 `x = 1458` |

### 2.3 底部正中原车小路图标（全天候常驻 + ACC 向上扩展）
- **全天候常驻区（即使挂 P 挡 / 关闭 ACC 也常驻！）**：
  - 精确 4 顶点梯形：**`(890, 580) → (1035, 580) → (1130, 639) → (795, 639)`**；
  - 结论：**`y = 580 .. 639` 居中区任何时候都不要放文字、数字或横条**！
- **ACC 巡航开启扩展区（`bus.sys.acc === true`）**：
  - 向上扩大至 **`x = 760 .. 1160, y = 495 .. 639`**（实车地图车标默认在 `car_up = 35` 基础上再上移 `acc_up = 55 px`，合计 `90 px` 上限）；
  - 底部居中组件应检测 `bus.sys.acc`，开启时自动上移至 `y <= 490` 或拆分避让。

## 3. 黄金推荐安全布局区（贴合原车结构、视觉最协调）

| 布局区 | 精确坐标范围 | 尺寸 | 设计建议 |
| :--- | :--- | :--- | :--- |
| **左翼黄金标准栏** | `x = 5 .. 300, y = 164 .. 508` | `295 × 344` | 与原版左侧信息框严丝合缝，底边与下方 `y = 518` 挡位梯形留 `10 px` 对称呼吸缝 |
| **右翼黄金标准栏** | `x = 1620 .. 1915, y = 164 .. 508` | `295 × 344` | 与左翼严格镜像对称，底边与 `y = 518` 车速梯形留 `10 px` 呼吸缝 |
| **加宽侧翼 / 圆形炮筒上限** | 左 `x >= 5`, 右 `x <= 1915`, 宽 `≤ 340`, `y = 164 .. 508` | 宽 `295 ~ 340`, 高 `≤ 344` | 外缘留 `5 ~ 12 px`，圆盘半径 `R ≤ 160`（圆心 `y = 336`）保证上下不撞顶栏和梯形 |
| **中央全天候无遮挡主舞台** | `x = 312 .. 1608, y = 164 .. 512` | `1296 × 348` | 放置中置 CarPlay 地图、大号车速、G 值仪、导航横幅的黄金区域（ACC 开时正中底边停在 `y <= 490`） |
| **底部斜边夹缝安全槽** | `x = 476 .. 1448, y = 518 .. 576` | `972 × 58` | 同时避开左右斜梯形（`468 / 1458`）和正中常驻小路（`y >= 580`），适合放细长油门/制动能量带（ACC 开时需拆成左右两翼避开 `x = 760..1160`） |
