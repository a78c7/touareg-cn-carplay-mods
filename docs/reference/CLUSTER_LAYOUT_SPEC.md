# 途锐 12 英寸全液晶仪表（数字驾驶舱 / Digital Cockpit）`1920×639` 精确界面几何规范

> 本规范基于 2023 款国行途锐（`MH2p_CN_VWG36_P2878`）实车正视标定照（含百度地图 BAP 车道指引激活态特写标定），结合已知渲染卡片（`x=5..300`、`x=1620..1915`）逐像素反算校准。所有使用 AI 编写 `v23` 60fps 自定义皮肤（`my_theme.js`）或调试仪表布局的车主与开发者，均应以此文档为唯一坐标真相源。

## 2. 原车自绘遮挡区（不可逆物理覆盖，禁止摆放关键信息）

大众仪表固件（FPK）会在 Window `58` 之上叠加以下 4 块原车图层，**皮肤画在这些区域的内容会被直接盖死或叠字**：

### 2.1 顶部多层遮挡（常态 `y = 0 .. 154` / 车道指引扩展至 `y = 0 .. 190`）
- **`y = 0 .. 82`（全黑不透明原车状态栏）**：方向罗盘、时钟（中心 `x = 965`）、辅助图标、车外温度。画在此区域**完全不可见**。
- **`y = 82 .. 154`（常态半透明原车导航顶栏）**：剩余距离、当前路名、预计到达时间，原车白字盖在最上层。
- **`y = 154 .. 190`（车道指引扩展遮挡带，百度/苹果地图实测）**：当导航下发 BAP 车道指引（FctID 24）时，原车仪表为在路名下方显示白色车道箭头，会将横贯全屏的半透明顶栏与底部白色边线向下撑高约 `36 px` 至 **`y ≈ 189 ~ 190`**。
- **`y = 190 .. 200`（`10 px` 全天候对称呼吸留白缝）**：为保证无论是否下发车道指引都绝不撞线，所有自定义卡片/表盘顶边统一对齐 **`y >= 200`**。

### 2.2 左下 / 右下原车斜梯形（挡位与车速，切勿按旧文档 `355 / 1565` 估算！）
> ⚠️ 实车正面像素校准发现：两块斜梯形底边比早期估算宽了约 `110 px`，若侧翼或底部组件伸入此区间会被直接切角遮挡。

| 遮挡区 | 精确 4 顶点多边形（顺时针） | 说明 |
| :--- | :--- | :--- |
| **左下原车挡位梯形**（`P / D / S`） | `(0, 518) → (314, 518) → (468, 639) → (0, 639)` | 顶边 `y = 518`，斜边从 `x = 314` 扩至底边 `x = 468` |
| **右下原车车速梯形**（`0 km/h`） | `(1612, 518) → (1920, 518) → (1920, 639) → (1458, 639)` | 顶边 `y = 518`，斜边从 `x = 1612` 扩至底边 `x = 1458` |

### 2.3 底部正中原车小路图标（全天候常驻 + ACC 向上扩展）
- **全天候常驻区（即使挂 P 挡 / 关闭 ACC 也常驻！）**：
  - 精确 4 顶点梯形：**`(890, 580) → (1035, 580) → (1130, 639) → (795, 639)`**；
  - 结论：**`y = 580 .. 639` 居中区任何时候都不要放文字、数字或横条**！
- **ACC 巡航开启扩展区（`bus.sys.acc === true`）**：
  - 向上扩大至 **`x = 760 .. 1160, y = 495 .. 639`**（实车地图车标默认在 `car_up = 35` 基础上再上移 `acc_up = 55 px`，合计 `90 px` 上限）；
  - 底部居中**文字/数字/进度条**组件应检测 `bus.sys.acc`，开启时自动上移至 `y <= 490` 或拆分避让。
- **⚠️ 给 AI 的关键区分（地图底图 vs 文字组件，切勿把地图拦腰截断！）**：
  - 上述 `y = 495 .. 639` 与 `y = 580 .. 639` **仅针对文字、数字、仪表条等前景信息组件**；
  - **CarPlay 实时地图底图（`ctx.drawMap`）完全可以直接向下延伸至 `y = 575` 甚至满铺至 `y = 639`**（底部正中被原车小车/车道线叠压一小块边角完全不影响看路，切勿将地图框在 `y = 495` 或 `512` 强行截断而留出大片黑底空挡）。

## 3. 黄金推荐安全布局区（贴合原车结构、全天候防车道顶栏撞线）

| 布局区 | 精确坐标范围 | 尺寸 | 设计建议 |
| :--- | :--- | :--- | :--- |
| **左翼黄金标准栏** | `x = 5 .. 300, y = 200 .. 508` | `295 × 308` | 顶部与原车车道指引扩展底线（`y = 190`）留 `10 px` 呼吸缝，底边与 `y = 518` 挡位梯形对称留 `10 px` 缝 |
| **右翼黄金标准栏** | `x = 1620 .. 1915, y = 200 .. 508` | `295 × 308` | 与左翼严格镜像对称，百度/高德/苹果导航下均绝不压线 |
| **加宽侧翼 / 圆形炮筒上限** | 左 `x >= 5`, 右 `x <= 1915`, 宽 `≤ 340`, `y = 200 .. 508` | 宽 `295 ~ 340`, 高 `≤ 308` | 外缘留 `5 ~ 12 px`，圆盘半径 `R ≤ 150`（圆心 `y = 354`）保证上下不撞车道顶栏和梯形 |
| **中央全天候无遮挡主舞台** | `x = 312 .. 1608, y = 200 .. 512` | `1296 × 312` | 放置中置 CarPlay 地图、大号车速、G 值仪、导航横幅的全天候安全区（ACC 开时正中底边停在 `y <= 490`） |
| **底部斜边夹缝安全槽** | `x = 476 .. 1448, y = 518 .. 576` | `972 × 58` | 同时避开左右斜梯形（`468 / 1458`）和正中常驻小路（`y >= 580`），适合放细长油门/制动能量带（ACC 开时需拆成左右两翼避开 `x = 760..1160`） |
